# Músicas

Coloque os mp3 aqui: track1.mp3, track2.mp3, track3.mp3 (ou os nomes que quiser,
só ajustar no array `playlist` no topo do script.js).

Capas das faixas vão em assets/music/covers/ (1.jpg, 2.jpg, 3.jpg).
Se não tiver capa, deixa o campo "cover" vazio no script.js que o disco gira sem imagem.
