# Músicas

Coloque aqui os arquivos .mp3 da playlist:

- `track1.mp3`
- `track2.mp3`
- `track3.mp3`

Para adicionar/remover faixas, edite o array PLAYLIST no topo do arquivo `script.js`:

const PLAYLIST = [
  { title: "nome da faixa", file: "assets/music/track1.mp3" },
];

O título mostrado no player é o campo "title" — pode ser qualquer texto, não precisa
bater com o nome do arquivo.
