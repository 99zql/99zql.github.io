# Imagens

Coloque aqui:

- `avatar.jpg` — sua foto de perfil (quadrada, min. 300x300px)
- `background.jpg` — imagem de fundo do site (paisagem, min. 1920x1080px)

Se usar outro nome/formato, ajuste os caminhos em `index.html` (linha do `<img>`)
e `style.css` (`.bg-layer { background-image: ... }`).
