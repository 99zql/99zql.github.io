# Ícones

Ícones SVG das redes sociais já incluídos (instagram, github, roblox, soundcloud, steam).
Para trocar por outros, mantenha o mesmo nome de arquivo ou atualize as referências
em style.css (seção ".media-card[data-platform=...]").

Adicione aqui também `favicon.png` (32x32 ou 64x64) se quiser um ícone de aba customizado.
